# Betul Senelmis Portfolio

This repository contains the source for the personal portfolio website hosted on GitHub Pages.

## Local preview

1. Install Ruby and Bundler.
2. Run:
   ```bash
   bundle install
   bundle exec jekyll serve
   ```
3. Open the local URL shown in the terminal (typically http://localhost:4000).

## Project contents

- `index.html` – main portfolio page
- `css/style1.css` – styling for the site
- `js/script.js` – scroll and mobile navigation behavior
- `img/` – image assets
- `video.mp4` – hero video background
- `_config.yml` and `Gemfile` – Jekyll/GitHub Pages configuration

## Deployment

This site is designed to be published as a GitHub Pages project site from the repository root.
